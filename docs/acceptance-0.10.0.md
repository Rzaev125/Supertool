# Приёмка 0.10 preview

Исправлено: реальный reader, запрещающий удаление CAB, больше не превращает завершённую установку в ошибку. Возвращается успешный результат с предупреждением об оставшемся кэше. Старый модуль освобождается; повторная явная установка пробует очистку. Владение CAB подтверждается ограниченной квитанцией и закреплённым хешем; неизвестные файлы не удаляются. Сохранённый CAB можно очистить и после следующей замены модуля. Таймер/фоновое сканирование не добавлены.

Первый пункт этапа 6: GIF и animated WebP. Проверяются кадры, неравные задержки, last-frame duration, конечные/бесконечные повторы, disposal restore-previous, прозрачность/полупрозрачность, уменьшение, первый кадр, усечение, границы, длительность и количество кадров/пикселей. Проверка результатов независимая — Pillow. Отдельно сохранены регрессии статических WebP/TIFF с линейным ICC и сохранность оригиналов. [Ограничения](animated-images.md).

Общие пины модулей остаются 0.9.0; версия приложения — 0.10.0. Исторические проверки 0.7/0.8/0.9 не переписываются. Подпись настоящими ключами, физический drag+Shift, смешанный DPI и чистая Windows VM остаются ручной приёмкой. Stable не переключается с 0.7.0.

Полная регрессия: 37/37 CTest, 159,83 с. Сборка /W4 без предупреждений. Один независимый обзор 0374782..460304a: блокирующих замечаний нет; решения и отложенные замечания в [review-0.10.0.md](review-0.10.0.md). Упаковка и публикация проверяются отдельно; итоговые хеши и ссылки фиксируются в отчёте выпуска после завершения.
