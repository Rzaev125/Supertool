# Проверка ShiftWheel 0.2.3 — 2026-10-22

Release x64 собран MSVC 19.44 / Windows SDK 10.0.26100 без предупреждений.
Финальный полный CTest: **12/12**, 0 ошибок, **63.34 секунды**.

## Новые форматы

- WebP/TIFF: чтение и запись, взаимные преобразования с PNG/JPG/BMP/AVIF.
  Реальные результаты проверены Pillow: формат, размер, цвет и alpha 0/128/255.
  WebP lossless и TIFF ZIP сохраняют видимые пиксели; JPG/BMP смешивают alpha
  с белым фоном. Проверены расширение TIF, lossy WebP, Unicode и пробелы.
- ICC: линейный профиль переводит серый 128 в sRGB около 188 с сохранением
  alpha 128 при импорте WebP/TIFF в PNG/WebP/TIFF/AVIF. Объявленный ICC должен
  сохраниться в промежуточном PNG; его потеря вызывает ошибку.
- Отклонены анимированные WebP, многостраничные TIFF, неприменённая ориентация
  EXIF, повреждённые файлы, PNG под чужим расширением, обрезанный RIFF и
  чрезмерные размеры. Проверены существующий результат и чужая временная папка.
- TIFF работает без modules. WebP без FFmpeg выдаёт сообщение об отсутствующем
  модуле. Новых бинарных зависимостей нет.
- Opus и AAC: WAV 44.1 кГц → Opus/AAC → WAV; ffprobe подтвердил кодек,
  аудиодорожку и длительность. MOV: H.264 + AAC, длительность и обратный MP4.
- SHA-256 оригиналов проверяется при каждой конвертации.
- OLE IDataObject/CF_HDROP проверяет каждый сектор колеса: 6 для изображений,
  7 для аудио, 6 для видео. Расширена палитра и ограничен индекс массива цветов.
- PNG-превью WebP, WAV, MP4, AVIF, XLSX и PDF созданы настоящим Direct2D-кодом;
  колёса изображений и аудио визуально осмотрены.
- Независимое read-only ревью проверило RIFF, ICC/alpha, AVIF-мост, worker,
  публикацию файлов и выбор секторов; дополнительных конкретных дефектов нет.

## Прежнее поведение

Пройдены policy, images, ole_drop_contract, animation_lifecycle,
worker_cancellation, application_smoke, worker_smoke, conversion_pdf,
conversion_office, conversion_media, conversion_avif и новый conversion_formats.
Первый общий запуск имел один ожидаемый конфликт окружения: работающий трей
0.2.2 удерживал mutex и не позволял smoke-тесту запустить второй экземпляр.
После проверки отсутствия дочерних задач старый экземпляр закрыт; полный
повторный прогон прошёл. Защита от второго экземпляра сохранена.

## Сборка и ресурсы

- EXE: **450048 байт**, статическая CRT.
- SHA-256: `DDC5F560832869869122A72BFA67276F7FE3E79C82796BCD546AE6561A7DF888`.
- Холодный трей: **0.0 мс CPU за 2004 мс**, **13.6 MiB**. Короткий замер
  на этой машине, без открытия колеса; это не универсальный бюджет ресурсов.
- FFmpeg/libavif запускаются только на время задачи, с пониженным приоритетом,
  ограничением потоков и существующим Windows Job для завершения потомков.
- Python используется только для тестов и не включён в приложение.

## Ограничения

Статические изображения: без анимации WebP/AVIF, многостраничного TIFF и HDR.
Выход 8 бит; ICC переводится в sRGB, метаданные не копируются. WebP export:
до 16383 по стороне; общий лимит — 40 млн пикселей. Opus — стерео 48 кГц,
128 кбит/с; AAC — ADTS 192 кбит/с. MOV — H.264/AAC, не ProRes.

Полный жест drag → Shift → drop из настоящего Проводника и переход между
мониторами разного DPI вручную не подтверждены. OLE/animation-тесты этого не
заменяют. Чистая Windows без инструментов разработки отдельно не проверена.
