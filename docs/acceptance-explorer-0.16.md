# Приёмка колеса в Проводнике — локальная 0.16

Дата: 24 октября 2026. Исходная ревизия: `3da7cb1`.
Статус: выполняется; настоящий Shift-drag пока не подтверждён.
Публикация и изменение публичных каналов не выполняются.

## Окружение и данные

- Windows 11 Pro, build 26300. EXE: `build/Release/ShiftWheel.exe`.
- Сохранённый Windows AppliedDPI — 96 (100%); это параметр системы, физический переход между мониторами не проверялся.
- Локальный режим включён. Настройка `auto_show_progress=0` сохранена.
- Проводник открыт через Computer Use, тестовое изображение видно в `build/explorer-check/01-single`.
- В `build/explorer-check` подготовлено восемь небольших файлов. `inputs.json` содержит SHA-256 оригиналов; `environment.json` — параметры окружения и хеш EXE.
- Путь длинного примера — 219 символов, с русскими и азербайджанскими именами. Это не проверка путей свыше MAX_PATH.
- Поддерживаемый API Computer Use предоставляет атомарный `drag` и отдельный `press_key`, без удержания модификатора во время drag. Нажатие Shift отдельно не равно проверке Shift-drag. Для настоящего жеста запрошена помощь владельца; отдельный механизм инъекции ввода не создаётся.

## Дополнительные автоматические проверки

После обычного drag сверены SHA-256 всех восьми оригиналов: без изменений; одиночная папка содержит только исходный PNG.

24 октября: `policy`, `batch_output`, `queue`, `job_store`, `tray_contract`, `worker_protocol` — **6/6 PASS, 2,12 с**. Журнал: `build/explorer-check-contracts.log`.

Эти тесты проверяют маршрутизацию и порог жеста, имена результатов, общую папку группы, очередь и восстановление, сводные уведомления, протокол worker. Они не доказывают взаимодействие настоящего источника drag из Проводника с глобальными hooks, не подтверждают реальный фокус и нажатие кнопки уведомления.

## Ограничения и продолжение

Шаг 3 плана остаётся открытым до записи фактических результатов доступных сценариев. Физический переход между мониторами с разным DPI, Windows 10 и дополнительные масштабы не считать проверенными без соответствующей приёмки. Настройки Windows и приложения ради теста не изменялись.
