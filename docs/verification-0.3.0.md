# Проверка ShiftWheel 0.3.0 — 2026-10-22

Release x64 собран MSVC 19.44 / Windows SDK 10.0.26100 с /W4 без предупреждений.
Полный итоговый CTest: **20/20**, 0 ошибок, **98.79 секунды**.
Журнал: `build/Testing/Temporary/LastTest.log`.

## Новые возможности и проверки

- Settings/options: строгий UTF-8, Unicode-пути, порядок форматов, диапазоны,
  атомарная запись, сохранение старого файла при отказе записи, неизменяемый
  снимок параметров задания. Некорректные настройки не создают результат.
- Пресеты проверены на реальных файлах: размеры и пропорции, отсутствие
  увеличения маленьких изображений, alpha PNG/TIFF/WebP/AVIF, качество JPEG,
  AVIF и WebP, высота видео, аудиобитрейт и его явное переопределение, DPI PDF.
- Очередь: FIFO, один активный файл, продолжение после ошибки, пауза, отмена,
  удаление ожидающих, атомарное добавление группы, лимит 256 ожидающих и
  100 записей истории. Параметры и папка копируются на момент добавления.
- OLE CF_HDROP: общие форматы смешанной группы, сохранение порядка файлов,
  изменение состава между DragEnter и Drop, несовместимые/слишком большие
  группы, отказ при заполнении очереди, настроенный порядок и один сектор.
  Принимается COPY, MOVE-only источник отвергается. Оригиналы не перемещаются.
- Worker: выбранная Unicode-папка, коллизии имён, снимок параметров,
  ограниченный набор наследуемых handles, фрагментированный/некорректный
  прогресс, повторная отмена и shutdown, завершение потомков, очистка staging.
- Engine: bounded parser, таймаут и потомок, удерживающий stdout pipe.
  Завершение потомков происходит до join читающего потока.
- Реальный FFmpeg: наблюдались 8 событий, включая промежуточный процент.
  В момент получения 100% результат уже существует. Ошибки и коллизии не
  сообщают 100%; SHA-256 исходников и существующих результатов сохраняется.
  Прогресс читает штатный `-progress pipe:1` ([документация FFmpeg](https://www.ffmpeg.org/ffmpeg.html)).
- Панель: 10 headless HWND-сценариев покрывают callbacks, выбор задачи,
  включение кнопок, неизвестный прогресс, скрытие, черновик настроек,
  ошибки сохранения с конкретной причиной, invalid UTF-8, порядок/минимум
  форматов, 150% DPI, размер окна и прокрутку с клавиатуры.
- Нативные окна «Задачи» и «Настройки» визуально осмотрены через computer-use;
  проверены читаемость, вкладки и тематические controls Windows.
  PNG-превью шести категорий пересозданы реальным кодом Direct2D.
- Независимое ревью обнаружило повторное открытие закрытой панели после
  завершения задачи. Исправлено: auto-show привязан к новому добавлению.
  Дополнительное ревью пресетов/конвертеров конкретных дефектов не обнаружило.

TEMP/TMP для тестов направлены в `build/test-temp`; junction/OLE и desktop
проверялись вне песочницы. Тесты создают только собственные фикстуры.

## Сборка и ресурсы

- EXE: **595968 байт**, статическая CRT, manifest 0.3.0.0, Common Controls v6.
- SHA-256: `F8C2BEBCFDF3680EAE623BC20A612952F8D7F48883C0D32A00FC8829F274287D`.
- Холодный трей: **0.0 мс CPU за 2002 мс**, **16.2 MiB**. Это короткий замер
  на данной машине, а не универсальная гарантия нагрузки.
- Обработка последовательная, рабочие процессы имеют пониженный приоритет.
  Economy/Balanced/Fast задают 1/2/до 8 потоков FFmpeg и AVIF; это не жёсткий
  процентный лимит CPU и не ограничение потоков LibreOffice/PDFium.
- В ожидании нет постоянного опроса прогресса. Движки запускаются на задачу.
  Python используется только для тестов и не входит в приложение.
- Пакет содержит прежние движки и лицензии; персональный ShiftWheel.ini
  исключается из ZIP без удаления с диска. Предыдущий выпуск сохранён.

## Что не подтверждено и что остаётся

Полный жест drag → Shift → drop из настоящего Проводника и переход между
физическими мониторами разного DPI вручную не подтверждены. Доступный API
автоматизации не поддерживает удержание Shift на время drag; синтетические
OLE и DPI-тесты этого не заменяют. Чистая Windows без инструментов разработки
отдельно не проверена.

Очередь и история живут в текущем сеансе и не восстанавливаются после выхода.
Сетевые пути, placeholders/reparse points, анимация, многостраничный TIFF,
HDR, HEIC, PPTX, OCR, GPU-кодеки, установщик и обновления в релиз не входят.
Подробные ограничения форматов и качества: README.md.
Доказательства предыдущего выпуска сохранены в verification-0.2.3.md.
