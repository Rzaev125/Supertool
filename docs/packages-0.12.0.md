# Локальные пакеты ShiftWheel 0.12.0

Проверено 23 октября 2026 года в `D:/IT/Project/Supertool`.
Исполняемый файл из локальной сборки коммита `2699d9a7e9e905b38e5d5c41108b3eb6b2cba23a`,
ProductVersion `0.12.0`. Исходный код приложения в этом этапе не менялся.
Пакеты не публиковались, каналы обновления не менялись.

## Результаты

- Созданы core/full ZIP и обычные Windows x64 установщики. Core содержит приложение и документацию; full также содержит шесть закреплённых модулей.
- Оба ZIP прошли CRC, проверку точных байтов EXE и `release.json`, полного состава и отсутствия INI, очереди, журналов и временных файлов. Для full проверены хеши каждого файла модулей, описи и квитанции.
- Состав и SHA-256 файлов ZIP совпали с манифестами установщиков: core — 29 файлов, full — 19 529. Оба настоящих установщика проверены `innounp -t`; извлечённые EXE и встроенные манифесты точно совпали со сборкой и sidecar JSON.
- Отдельные установщики с compile-time изоляцией прошли установку, запуск, блокировку установки при работающем приложении, повторную установку и удаление. Сохранены INI и чужие файлы, включая вложенные. Не изменились регистрация и ярлыки основной установки. Временный клон деинсталлятора завершил собственную очистку.
- Full дополнительно прошёл настоящую конвертацию медиа установленным EXE: числовой прогресс FFmpeg, 100% после публикации результата, отсутствие ложных 100% при ошибке и коллизии, сохранность оригиналов.

Проверка повторной установки той же версии здесь не заменяет переход между разными версиями на чистой Windows VM.
Настоящий drag в Проводнике, несколько мониторов с разным DPI и Authenticode остаются открытыми пунктами приёмки.
Установщики не имеют подписи издателя; подключение настоящего сертификата владельца остаётся отдельной задачей.
