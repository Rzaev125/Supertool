# Очередь и история — 0.8

`ShiftWheel.queue` рядом с EXE хранит ожидающие задачи, до100 завершённых задач,
до100 завершённых групп, счётчики незавершённых групп и снимки параметров.
Запись атомарная и выполняется при изменении очереди; события прогресса не
перезаписывают файл. Это локальное состояние содержит пути файлов и сообщения;
оно не входит в диагностический отчёт, ZIP или установщик и никуда не отправляется.

После запуска найденная очередь с ожидающими заданиями восстановлена на паузе.
История без ожидающей работы не ставит новые конвертации на паузу. Кнопка «Восстановить
очередь» явно разрешает запуск ожидающих задач; «Очистить очередь» отказывается
от ожидающих. Прерванная активная задача получает статус «Прервано» и запускается
заново только через «Повторить». Продолжение недокодированного видео не выполняется.
Новые задания, добавленные при паузе, также ждут явного продолжения.

Перед запуском проверяются доступность источника, его размер и время изменения.
Если файл исчез или изменился, задача завершается понятной ошибкой без запуска
движка; явный «Повторить» принимает текущий файл и создаёт новый снимок идентичности.
Это проверка size/mtime, а не криптографическая идентификация содержимого.
Результат всегда получает свободное имя по существующему правилу публикации.

Поиск истории фильтрует завершённые строки по имени, формату, статусу и деталям;
текущая работа и ожидающие строки остаются видимыми. В деталях приведена сводка
группы. «Очистить историю» удаляет только завершённые записи, без удаления
источников или результатов. Очередь и история переживают штатное закрытие;
последнее сохранённое активное задание после аварии становится прерванным.

Повреждённое/слишком большое хранилище отклоняется целиком, сообщение показывается
в панели; источники не затрагиваются. Новое изменение очереди создаёт новое
состояние. Отказ записи приостанавливает очередь и показывается в панели.
Папка приложения должна допускать запись. Для сброса всего состояния закройте
приложение и переместите `ShiftWheel.queue` в резервную папку.

С 0.11 выбранный видеокодек сохраняется в SWQ2. Старые SWQ1 читаются с прежним кодеком по контейнеру. Старые версии приложения SWQ2 не читают: перед возвратом на старую версию завершите очередь и сохраните нужную историю отдельно.
