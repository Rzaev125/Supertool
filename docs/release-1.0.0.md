# Supertool 1.0.0 — Первая версия

Первый официальный выпуск для Windows x64.

Обновлённый выпуск **Supertool 1.0.0** заменяет первоначальную сборку с прежним названием по распоряжению владельца. Установщики, ZIP и EXE используют Supertool. Уже установленная прежняя 1.0.0 не увидит более новую версию: скачайте и установите новый пакет вручную, предварительно завершив приложение через трей. Настройки сохраняются.

- Конвертация файла или группы через перетаскивание с Shift и колесо форматов.
- Изображения: JPEG, PNG, BMP, TIFF, WebP, AVIF, HEIC и GIF; поддерживаемые HDR-фото переводятся в SDR.
- Видео и аудио: H.264, HEVC, AV1 и популярные контейнеры; автоматический выбор доступного GPU с переходом на CPU при ошибке.
- DOCX, XLSX, PPTX и PDF; извлечение TXT из сканов PDF с OCR на русском, английском и азербайджанском.
- Тёмные настройки, именованные профили по категориям и пояснения о размере, прозрачности и метаданных.
- Тихая последовательная очередь, общая папка результатов группы, уведомление с кнопкой открытия папки и восстановление очереди после перезапуска.
- В подробностях задачи — подтверждённые движки/кодировщик, время и размеры файлов.

## Что скачать

- **Full setup** (`Supertool-1.0.0-win-x64-setup.exe`) — установка со всеми модулями для работы офлайн.
- **Full ZIP** (`Supertool-1.0.0-win-x64.zip`) — переносимая полная сборка.
- **Core setup / Core ZIP** — небольшой комплект с базовыми изображениями; дополнительные модули устанавливаются через настройки.
- `Supertool-1.0.0-source.zip` — исходники проверенной ревизии. CAB-файлы компонентов опубликованы отдельно под именами `Supertool-module-*`; прежние имена CAB сохранены как совместимые ссылки-файлы для старых каталогов; их версия0.9.0 независима от версии приложения, содержимое и SHA-256 не менялись.

Установщики работают для текущего пользователя. Перед установкой или обновлением закройте Supertool через «Выход» в трее. Оригиналы и существующие результаты не перезаписываются; пользовательские настройки сохраняются.

## Подпись и ограничения

**EXE и установщики не имеют Authenticode-подписи:** сертификат Windows Code Signing ещё не подключён. Windows может показывать неизвестного издателя. Для файлов публикуются SHA-256; манифест обновления подписывается существующим ECDSA P-256 ключом `shiftwheel-prod-1`, публичный ключ закреплён в официальной сборке.

Ручные проверки Проводника, физические DPI, чистая Windows/VM и Windows10 в этом выпуске не выполнялись по указанию владельца. Автоматические нативные и реальные конверсионные проверки выполняются перед публикацией. Поддержка конкретного GPU зависит от оборудования и драйвера; обнаружение кодера не выдаётся за успешное аппаратное кодирование.

Сложная вёрстка Office может меняться. PDF → Office с восстановлением вёрстки, RAW, произвольный HDR и HDR-видео не поддерживаются. OCR может ошибаться. Точный размер результата заранее не обещается.
