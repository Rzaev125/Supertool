# ShiftWheel: дизайн и первая проверяемая версия

## Согласованные требования

Windows-утилита: пользователь начинает перетаскивать файл, удерживает Shift,
выбирает формат в круговом меню у курсора и отпускает мышь. Пользователь хочет
популярные категории: изображения, видео, аудио, DOCX, XLSX и другие офисные
документы. Главный приоритет — небольшая нагрузка на компьютер. Выбранный и
подтверждённый стек: C++ + Win32 + Direct2D; конвертеры в отдельных процессах.

Оригинал сохраняется. По умолчанию результат появляется в исходной папке с
новым именем при совпадении. Интерфейс русский. Всё преобразование локальное.

## Граница первого этапа (решение исполнителя)

Первый этап — запускаемый нативный прототип, проверяющий самое рискованное место:
присоединение drop target к уже идущему перетаскиванию. Это не готовый
универсальный конвертер. Windows 10/11 x64, мышь, Проводник и рабочий стол.
PNG/JPEG/BMP -> PNG/JPEG/BMP через Windows Imaging Component (WIC).
Конвертация в отдельном процессе, одна задача одновременно, отмена через трей.
Пакеты FFmpeg/LibreOffice, PDF, TIFF/анимации, HEIC/AVIF, пакетная обработка и
автозапуск остаются в дорожной карте; приложение не обещает их в интерфейсе.

## Поведение

- Активировать колесо только после движения с зажатой левой кнопкой из
  Проводника/рабочего стола за системный порог начала перетаскивания + Shift.
- Хуки только наблюдают события; не подменяют ввод и не читают выделение файлов.
- Временное верхнее окно без активации зарегистрировано как OLE IDropTarget.
  Источник определяется по CF_HDROP в реальном IDataObject.
- Принимать ровно один существующий обычный локальный файл. Неподдерживаемые
  источники, папки, несколько файлов, виртуальные объекты получают NONE.
- Сектор выбирается движением. Центр и пространство вне круга не запускают
  преобразование. Отпускание Shift закрывает колесо; Esc закрывает колесо и
  остаётся доступным исходному приложению для отмены drag.
- При Drop обязательно повторно проверять файл, Shift, сектор и разрешённый
  источником COPY. Никогда не возвращать MOVE.
- Сброс завершает исходное перетаскивание. Продолжение drag с готовым результатом
  в этом этапе отсутствует.
- В трее: показать колесо для ознакомления, открыть папку последнего результата,
  отменить задачу, выйти. Ознакомительное колесо не запускает конвертацию.
- Колесо закреплено в точке появления, сдвинуто в рабочую область монитора;
  расположение секторов постоянно. Перерисовка только по событиям.
- Нет постоянного опроса, анимационного таймера, автозапуска и административных прав.

## Данные и процесс конвертации

WIC декодирует единственный кадр с ограничением 40 млн пикселей и 32768 пикселей
по каждой стороне (дополнительный предел выбран исполнителем). Многокадровый
ввод отклоняется. JPEG/BMP получают белый фон под прозрачностью, JPEG quality
0.90; PNG сохраняет альфа-канал. Прототип не обещает сохранение EXIF/ICC и
профессиональную цветопередачу; ориентацию EXIF необходимо либо применить,
либо отклонить неподдерживаемое значение с объяснением.

Результат сначала записывается в уникальный временный файл той же папки,
публикуется после commit энкодера через переименование без замены существующего
файла. Ошибки и отмена удаляют только временные файлы этой задачи. Ошибки доступа
не запускают UAC и показываются пользователю. Процесс запускается напрямую через
CreateProcessW с корректным quoting, в Job Object с KILL_ON_JOB_CLOSE и приоритетом
BELOW_NORMAL. На завершение ждёт блокирующий поток только пока есть задача.

## Проверка

Автоматически: выбор сектора/нейтральной зоны, порог жеста и rearm, COPY/NONE,
имена результатов и quoting; реальная PNG -> JPEG с белой прозрачностью,
сохранность оригинала, отказ при совпадении пути/существующем результате,
битый/многокадровый/слишком большой файл, кириллица и пробелы в пути.

Нативный smoke: старт/выход, реальный OLE source из тестового процесса с
CF_HDROP, приём и отмена, отсутствие MOVE; измерение CPU/RAM при ожидании.
Ручная проверка Проводника, разных DPI/мониторов, Esc/Shift и визуального вида
обязательна перед заявлением о готовности жеста для повседневной работы.

## Дорожная карта

1. Прототип жеста и изображений из этого документа.
2. Каталог поддерживаемых направлений + очередь + FFmpeg (видео/аудио).
3. Изолированный LibreOffice headless (документы/таблицы/презентации), проверка
   оформления, шрифтов, листов CSV и настроек печати PDF.
4. PDF-движок, дополнительные изображения, пакеты модулей и настройки качества.
5. Пакетная обработка, установка/обновления, аппаратное кодирование и режимы
   ограничения ресурсов. PDF -> редактируемый Office/OCR — отдельный проект.

## Рабочая среда

Новый пустой репозиторий без коммитов, .git доступен только на чтение.
Работа в выделенной папке Supertool без изменения git-метаданных. Доступны
MSVC 14.44.35207, CMake/Ninja из Visual Studio 2022 Build Tools и SDK 10.0.26100.0.
