# Проверка Supertool 0.2.2 — 2026-10-22

Release x64 собран MSVC 19.44 / Windows SDK 10.0.26100 без предупреждений.
Полный CTest: **11/11**, 0 ошибок, **61.41 секунды** после исправлений ревью.

## AVIF

- Четвёртый сектор изображений; PNG/JPEG/BMP → AVIF и AVIF → PNG/JPEG/BMP/AVIF.
- Настоящий OLE IDataObject/CF_HDROP проверяет выбор AVIF в четвёртом секторе.
- Реальные файлы проверены независимым декодером Pillow: формат AVIF, размеры,
  цвет, alpha 0/128/255. PNG/AVIF сохраняют прозрачность, JPG/BMP получают белый
  фон и правильное смешивание полупрозрачного красного с белым.
- Проверены кириллица и пробелы в путях, SHA-256 оригиналов, существующий
  результат, чужая временная папка, отсутствие AVIF-модуля. Встроенный PNG→JPG
  продолжает работать без папки modules.
- Повреждённый, обрезанный и замаскированный PNG под AVIF отклоняются без
  частичного результата. Анимация, irot и HDR PQ также отклоняются.
- На ревью найден случай неверной гаммы. Без ICC теперь принимаются только
  sRGB/неуказанные primaries и transfer. Линейный и wide-gamut AVIF без ICC
  отклоняются. Встроенный ICC используется WICColorTransform для перевода
  пикселей в sRGB и не копируется в результат.
- Регрессия с линейным RGB ICC проверяет серый 128 → примерно 188 и сохранение
  alpha 128 для PNG→AVIF, AVIF→PNG и AVIF→AVIF. Если объявленный ICC теряется
  при декодировании, конвертация завершается ошибкой.
- Свежий read-only reviewer повторно проверил исправление; новых конкретных
  дефектов не обнаружено. Контексты/transform удерживаются COM-ссылками.
- PNG-превью четырёх секторов создано настоящим Direct2D-кодом и осмотрено.

## Ограничения

Полный жест drag → Shift → drop из настоящего Проводника и переход между
мониторами разного DPI вручную не подтверждены. OLE/animation-тесты этого не
заменяют. Отдельная чистая Windows без инструментов разработки не проверена.

AVIF: только статические SDR-изображения, вывод 8 бит; цветное сжатие с потерями.
HDR PQ/HLG, анимация, неприменённые поворот/отражение/кадрирование и неподдержанные
цветовые характеристики без ICC отвергаются. EXIF/XMP не переносятся. Политика
проверяет фиксированный диагностический формат avifdec 1.4.2; замену этой
библиотеки следует сопровождать повторным прогоном AVIF-тестов.
