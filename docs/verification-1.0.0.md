# Проверка первого выпуска ShiftWheel 1.0.0

Дата: 24 октября 2026. Система проверки: Windows 11 Pro x64. Кандидат собран отдельно в `build/release-1.0`, Release MSVC, `SHIFTWHEEL_LOCAL_DEVELOPMENT=OFF`, с настоящим публичным ключом `shiftwheel-prod-1`. Рабочая локальная сборка и её INI не заменяются.

## Автоматические проверки

Итоговый Full: **60/60 PASS, 319,37 с**, код завершения 0, автоматических пропусков нет. Пройдены нативные тесты, настоящий запуск приложения, профили, изображения/метаданные/HDR, видео/аудио/GPU fallback, документы, презентации, OCR и пакетные контракты. Штатный runner удалил свои фикстуры после успеха.

- Новый контракт release tooling: 2/2 PASS; перед исправлением обе проверки воспроизвели ошибки. Проверяются сохранение закреплённого URL каталога и предзагрузка публикации с заданным заголовком/текстом без сетевой публикации.
- Пакетные тесты теперь получают точный EXE кандидата: старое предположение `build/Release` воспроизвело отказ проверки версии, исправленные `package_policy` и `installer_cleanup` прошли 2/2. Защита от несовпадения версий сохранена.
- В тестовом цикле уведомления добавлена обработка ожидающего события таймера после последнего Sleep. Продуктовая анимация не менялась. Целевой тест прошёл пять последовательных повторов.
- Штатный тихий запуск и завершение кандидата: PASS. Короткая выборка простоя: CPU 0 мс за 2008 мс, рабочий набор 19,9 MiB; это не измерение продолжительной нагрузки.
- Версионные декларации и ProductVersion: 1.0.0.

## Пакеты и установка

- Core: 44 файла; Full: 19544 файла, включая 19500 файлов модулей. SHA-256 каждого файла модуля проверен по закреплённой описи. ZIP и манифест полезной нагрузки соответствующего установщика имеют одинаковый состав и хеши.
- SHA-256 общего EXE: `8de3f4f51bf8afda5334ae7b795e1a2e2e4b286364fcd55133c14e3f9af5949b`.
- Проверены имена, отсутствие дубликатов, личного INI, очереди, диагностик, временных переключателей модулей и приватных ключей в пакетах.
- Изолированные Core/Full установщики: установка, повторная установка и удаление PASS, проверены все установленные файлы. INI и посторонние файлы сохраняются; настоящие пользовательские ярлыки и регистрация установки не меняются. Проверены отказы при работающем приложении, неправильном каталоге и отсутствии явного тестового флага.
- Из установленного Full выполнена настоящая медиаконвертация с проверкой прогресса и сохранности исходника. Интерактивный экран установленного приложения не проверялся; тихий запуск того же EXE проверен отдельно.
- Шесть CAB сохраняют прежние версию 0.9.0, байты и SHA-256. Независимый номер модуля не означает старую версию приложения. Каталог направляет их на выпуск v1.0.0.

## Подписи и публикация

Манифест подписан существующим приватным ключом только штатным скриптом; ключ не копировался в проект и не публикуется. Нативный verifier кандидата подтвердил подпись и минимальную версию 1.0.0. SHA-256 публичного ключа: `f6696881802a9b0ab6d2a025e29abdcb87fbc0ac11fb5c86e5f9457d0cd0a391`.

EXE и оба установщика имеют фактический статус Authenticode `NotSigned`. Сертификат Windows Code Signing пока не подключён. Строгие требования сертификата в release workflow сохранены; выпуск подготавливается разрешённым ручным путём.

Выпуск [ShiftWheel 1.0.0 — Первая версия](https://github.com/Rzaev125/Supertool/releases/tag/v1.0.0) опубликован 24 октября 2026. Состояние latest, не черновик, не prerelease. Все **26 файлов** совпали по удалённым SHA-256 и размерам; для каждого проверена общедоступность до переключения подписанного и совместимого старого каналов.

Независимая проверка после публикации подтвердила точные байты обоих публичных каналов и подпись скачанного манифеста нативным verifier. Тег `v1.0.0` указывает на `ebafb9530af72193567ffd815d0c850627b76ed4`; архив исходников содержит ровно 329 файлов этой ревизии, без пользовательских настроек и приватных ключей. SHA-256 архива: `9e8b8c9551cff142239aec604594fbd8e1ed4c305e370db4aecddcb354326102`. Последующие коммиты каналов и этого отчёта не меняют зафиксированный тег или опубликованные пакеты.

Временные деревья неуспешных тестовых прогонов и изолированных установщиков удалены после сохранения свидетельств. Обычная локальная сборка снова запущена из прежнего каталога; SHA-256 INI остался `7e509f07ec0cb5673c5a769559b43126e1e289e4f14462134274e7c6a1faa5a1`.

## Границы проверки

Ручные тесты пропущены по указанию владельца. Чистая Windows/VM, Windows 10, физические DPI и полная ручная приёмка Проводника не заявляются. Ранее владелец подтвердил одиночный Shift-drag в локальной сборке: колесо появилось, JPG создан, очередь не открылась; это не новая приёмка всех сценариев 1.0.0.

Доступность GPU зависит от оборудования и драйвера. Успешное обнаружение кодера не приравнивается к успешному кодированию. Реальные автоматические проверки включают аппаратный путь и CPU fallback. Ограничения форматов и OCR перечислены в [примечаниях к выпуску](release-1.0.0.md).
