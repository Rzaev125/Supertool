# Проверка Supertool 0.6.0 — 2026-10-23

Release x64 MSVC /W4 собран без предупреждений. Новый модуль WinHTTP/BCrypt
не добавляет runtime или службу.

В общем прогоне проверены 26 тестов: 25 PASS, один новый тест выявил ошибку
самой фикстуры реестра (непостоянные родительские ключи запрещали обычные дочерние
ключи, Win32 1021). После исправления фикстуры целевой прогон updates_policy,
options, panel_contract: 3/3 PASS, 1.78s. В сумме все 26 выбранных проверок имеют
успешный результат. application_smoke исключён: работает пользовательская копия
на рабочем столе, её не завершали и не заменяли. Код защиты версии и новые
настройки проверены через нативные контрактные тесты.

Новый тест проверил числовое сравнение версий, строгий HTTPS-манифест, потоковую
загрузку, SHA256, отказ при неверном хеше/размере, отмену, включение/выключение
автозапуска в изолированной ветке реестра. Настоящие процессы проверили ожидание
родительского процесса, вызов установщика и повторный запуск приложения.
Этот стенд использует отдельную сборку с тестовым путём; в продукте такой
переключатель отсутствует. Тестовый установщик фиксирует запуск и не устанавливает
продукт в реальный профиль. Настоящее обновление установленной копии в рабочем
профиле и вход в Windows после перезагрузки отдельно не проверялись.

Существующие реальные конвертации PDF, Office, видео, аудио, AVIF, WebP, TIFF,
HEIC, PPTX и OCR прошли. NVIDIA/Intel hardware и CPU fallback также прошли.
Логи: build/release-0.6.0-full-ctest.log и LastTest.log.

Канал GitHub задан для Rzaev125/Supertool. Публикация установщика и манифеста
не должна считаться выполненной до подтверждения их доступности на GitHub.
Документация поведения и ограничений: docs/updates.md.
После независимого ревью исправлены: генерация четырёх строк манифеста,
перезапуск приложения при отказе запуска установщика, блокировка повторных
автоматических попыток в сессии после неудачи, откат настроек при ошибке
автозапуска, обработка длинного пути переносимой копии и запуск отложенного
обновления после очистки/удаления последнего задания очереди.
Итоговый целевой прогон: updates_policy, installer_payload, options,
panel_contract — 4/4 PASS, 4.11s. Реальный процессный тест также подтвердил
возврат к приложению при некорректном исполняемом файле установщика.
Сгенерированный PowerShell-манифест принят настоящим C++-парсером.
Независимое повторное ревью: открытых важных замечаний нет.
