# Необязательные модули 0.9

Базовая сборка содержит колесо, очередь, настройки и конвертер JPEG/PNG/BMP/TIFF через Windows WIC. В ней нет скрытой загрузки движков. Выберите **Настройки → Модули**, компонент и **Установить / обновить**. Размер и зависимости показаны перед действием. PDF автоматически устанавливается перед Office или OCR, если его ещё нет. OCR содержит русский, английский и азербайджанский языки.

Компоненты: FFmpeg (видео/аудио/WebP), AVIF, HEIC, PDFium (PDF), LibreOffice (DOCX/XLSX/PPTX), Tesseract (OCR). Существующие модули без квитанции совместимы, но их версия честно показывается как неизвестная. Полная офлайн-сборка содержит все компоненты и не требует сети.

Изменения разрешены только при пустой очереди. Загрузка и распаковка идут в отдельном потоке. Нажатие «Отменить загрузку» оставляет установленную версию доступной. Параллельно запущенный CLI-конвертер защищён общей файловой блокировкой. Установка проверяет свободное место, HTTPS, точный размер CAB, закреплённый SHA-256, перечень файлов и SHA-256 каждого файла. Подпись настоящим ключом пока не подключена: владелец ещё не предоставил ключи. Каталог и хеши встроены в EXE; скачанный catalog.json не используется как доверенный источник.

Новая версия распаковывается в `modules/pkg-<GUID>`. Маленький файл `.active-<id>` переключается атомарно только после проверки всего пакета. При сбое раньше этого момента используется прежняя версия. Конвертер держит блокировку до завершения движков. Удаление сперва отключает модуль, затем удаляет только неизменённые файлы из подтверждённого инвентаря. Неизвестные и изменённые файлы сохраняются. Старые офлайн-модули без подтверждённого инвентаря сохраняются целиком; это может оставить занимаемое ими место на диске. Не удаляйте папки модулей во время конвертации.

После аварийного отключения питания незавершённая загрузка может остаться отдельным неактивным `pkg-*`/CAB в modules. Фоновая очистка неизвестных каталогов намеренно отсутствует. Перед ручным удалением закройте ShiftWheel и все его CLI-процессы; активные каталоги указаны в `.active-*`. Не удаляйте каталог только по похожему имени.

Сборка: `python scripts/build-modules.py` создаёт CAB в `out/module-assets` и закреплённый `resources/module_catalog.inc` **до** компиляции. Сохраняйте эти CAB вместе с исходной версией: повторная сборка CAB может отличаться байтами из-за времён файлов. `scripts/package.ps1 -Distribution core|full` создаёт отдельную новую папку и ZIP; `scripts/build-installer.ps1 -Distribution core -PayloadDirectory out/ShiftWheel-0.9.0-core` создаёт базовый установщик. Сборочные Python/PowerShell не нужны на компьютере пользователя.

Модули загружаются из предварительного выпуска `v0.9.0-preview`. Стабильный канал остаётся на 0.7.0; 0.8 и 0.9 требуют отдельной приёмки перед стабильной публикацией. Настоящие Windows VM, физический drag+Shift и разные масштабы мониторов остаются открытыми проверками.
