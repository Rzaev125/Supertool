# ShiftWheel 0.9.0 preview

[Предварительный выпуск](https://github.com/Rzaev125/Supertool/releases/tag/v0.9.0-preview), [draft PR #2](https://github.com/Rzaev125/Supertool/pull/2), база — ветка 0.8. Stable проверен на сервере: 0.7.0, main не изменён.

Реализован этап 5: отдельная базовая программа и шесть необязательных модулей; HTTPS-загрузка по явной команде, закреплённые хеши CAB/инвентаря/файлов, блокировка замены во время конвертации, атомарное переключение версии. Полная офлайн-сборка сохранена. [Инструкция](modules-0.9.md).

Проверки: MSVC /W4 без предупреждений; последняя полная регрессия 36/36, 170,28 с; дополнительные native callbacks и упаковка 4/4, 7,75 с; последняя изолированная packaging-policy проверка 8 сценариев PASS. Core install/upgrade/uninstall/запуск — 21 файл, full fixture lifecycle сохранён. ZIP CRC/точный набор файлов и хеш каждого модуля проверены, личных INI/очереди/журналов нет. Установщики: все 23 / 19523 записей прошли проверку целостности; встроенные EXE и payload-манифесты совпали с проверенными исходными файлами. ZIP и setup имеют одинаковый payload: 21 / 19521 файл.

Все шесть CAB установлены локально с полной проверкой. Из отдельно установленных модулей выполнены AVIF, HEIC, видео, DOCX/PDF и OCR. Реальная публичная HTTPS-проверка проводится после публикации; этот отчёт не выдаёт локальный transport за сетевую приёмку.
