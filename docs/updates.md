# Обновления и автозапуск — 0.6.0

В настройках доступны «Запускать вместе с Windows», автоматические обновления
и HTTPS-адрес канала. При входе в Windows запускается трей без открытия панели.
Автозапуск выключен по умолчанию. Он регистрируется только после сохранения
настройки через HKCU Run: quoted EXE + --startup. Windows может отдельно
отключить его в диспетчере задач; приложение не обходит это отключение.
Удаление установленной копии удаляет только её собственную запись Run.
Переносимую папку после включения автозапуска нельзя перемещать без повторной
настройки. Удаление папки вручную не удаляет запись Run.

Канал: https://raw.githubusercontent.com/Rzaev125/Supertool/main/updates/stable.txt
Проверка выполняется через 30 секунд после запуска, затем раз в сутки.
В трее есть «Проверить обновления». При ошибке автоматической проверки окно
не открывается. Ручная проверка показывает результат или ошибку уведомлением.

Установленная копия в %LOCALAPPDATA%\Programs\ShiftWheel загружает новый
установщик в %LOCALAPPDATA%\ShiftWheel\Updates, проверяет размер и SHA256,
ждёт завершения всей очереди и закрывается штатно. Отдельная копия нативного
помощника ждёт выхода исходного процесса, запускает установщик без UAC
и открывает приложение снова. При отказе установщика открываются настройки
прежней копии. Конвертации не прерываются для обновления. Пауза с непустой
очередью также откладывает установку. Переносимая копия только уведомляет
о новой версии: автоматическая установка не должна незаметно создавать
другую копию приложения. Отключение обновлений во время загрузки делает её
результат неприменимым. При выходе приложения фоновая операция отменяется.

Манифест — четыре ASCII-поля, без команд и параметров запуска:

```
version=0.6.0
url=https://github.com/Rzaev125/Supertool/releases/download/v0.6.0/ShiftWheel-0.6.0-win-x64-setup.exe
size=<точное число байтов>
sha256=<64 шестнадцатеричных символа>
```

Неполные поля, дубликаты, неверные версии, HTTP, credentials в URL, фрагменты,
слишком большие манифесты/пакеты отклоняются. Пакет ограничен 1 GiB,
манифест 16 KiB. Загрузка потоковая; размер пакета не превращается в расход RAM.
WinHTTP проверяет TLS и запрещает перенаправления HTTPS → HTTP; сетевые вызовы
имеют таймауты, общая загрузка ограничена 20 минутами. SHA256 защищает от
несоответствия пакета манифесту. Доверие издателю обеспечивается HTTPS-каналом:
взлом канала или GitHub-аккаунта этим хешем не обнаруживается. Подпись издателя
в текущем выпуске отсутствует. Проверенные кэшированные файлы после прерванной
установки можно удалить при закрытом приложении из папки Updates.

Публикация: загрузить setup.exe в GitHub Release v0.6.0, затем выполнить
scripts/make-update-manifest.ps1 и опубликовать updates/stable.txt в main.
Сначала публикуется пакет, затем манифест. Не публикуйте манифест со ссылкой
на ещё недоступный пакет. Версия 0.5.0 не содержала клиента обновлений:
для первого перехода на 0.6.0 нужно запустить новый установщик вручную.

Протокол использует официальные API:
https://learn.microsoft.com/en-us/windows/win32/winhttp/option-flags
https://learn.microsoft.com/en-us/windows/win32/setupapi/run-and-runonce-registry-keys
