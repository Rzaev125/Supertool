# Локальная 0.15.0

Добавлены оригинальные EXIF-повороты HEIC без повторного применения контейнерных irot/imir, включая HDR→SDR, ICC и растровые мосты. Новый явный режим сохраняет дату, автора и copyright из JPEG/TIFF/HEIC в JPEG/TIFF, включая Unicode XPAuthor, без GPS и скрытого копирования EXIF.

Старые режимы метаданных сохраняют поведение. Настройки и очередь поддерживают новый режим; ограничения отката и точный список полей: [метаданные фото](photo-metadata.md).

Это локальная сборка разработки. Пакеты0.14, публичные выпуски, канал обновлений и ключи доверия не менялись. Новые ZIP/установщик0.15 не выпускались. Проверки: [приёмка](acceptance-0.15.0.md), [обзор](review-0.15.0.md).
