# Проверка переименования в Supertool

24 октября 2026, Windows 11 x64. По распоряжению владельца переименованы интерфейс, EXE и CMake target, ресурсы логотипа/ICO, шаблон установщика, будущие имена пакетов, сборочные команды, тестовые инструменты и документация. На GitHub заголовок и описание v1.0.0 используют **Supertool 1.0.0 — Первая версия**.

- Нативные тесты заголовка настроек и бренда уведомления: RED на прежнем названии, затем GREEN.
- **Full 61/61 PASS, 358,75 с**, без автоматических пропусков, фикстуры удалены runner. Проверены настоящий запуск приложения, нативные контракты и реальные конвертации изображений, видео/аудио, документов, презентаций, OCR и HEIC.
- Ревью обнаружило два замечания. Переход между установленными `ShiftWheel.exe` и `Supertool.exe` терял распознавание автозапуска; реальный тест в изолированном HKCU воспроизвёл RED, после исправления GREEN в обоих направлениях. `module_probe` не принимал старые имена CAB; настоящий закреплённый PDFium воспроизвёл `asset missing`, после исправления установился с проверкой хеша.
- После исправления автозапуска финальный EXE перелинкован. Повторно пройдены **4/4** затронутые проверки: branding, updates_policy, application_smoke и worker_smoke. Полный конверсионный прогон относится к сборке до этого последнего исправления автозапуска; движки конвертации после него не менялись.
- Офлайн-контракты bootstrap: **11/11 PASS**, включая старый префикс CAB. Все шесть настоящих модулей проверены `build-modules.py --verify-only`: исходные описи и SHA-256 сохранены, URL каталога не менялись.
- Из финального EXE собран изолированный Core-установщик: установка, проверка 44 файлов, повторная установка, блокировки работающего приложения, неправильного каталога и отсутствия тестового флага, удаление — PASS. INI и посторонние файлы сохранены; настоящие ярлыки/регистрация пользователя не менялись. Обновление реально установленной старой версии отдельно не выполнялось.
- Свойства финального файла: ProductName/InternalName `Supertool`, OriginalFilename `Supertool.exe`, ProductVersion `1.0.0`. SHA-256 EXE: `e09c255b00919360066963ca4f09d5d5c32ee3d753d928864d2ae5e3f57da733`.
- Старый пользовательский INI сохранён на месте: SHA-256 `7e509f07ec0cb5673c5a769559b43126e1e289e4f14462134274e7c6a1faa5a1`.

Ручные тесты пропущены по указанию владельца. Новый бинарный релиз не публиковался: прежние 26 файлов, тег и подписанные каналы 1.0.0 сохранены. [Правила совместимости](branding.md) описывают оставшиеся технические имена и старые пользовательские интеграции.
