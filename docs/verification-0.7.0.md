# Проверка Supertool 0.7.0 — 2026-10-23

Release x64, C++20/MSVC /W4: сборка без предупреждений.
Область выпуска — этапы 1–2 утверждённого плана: тихая работа, уведомления
групп, четыре раздела настроек, понятные файловые ошибки и диагностика.

Первый общий прогон: 28/28 PASS, 154.32 s (application_smoke исключён).
После независимого ревью добавлены NIF_SHOWTIP для подсказки трея версии4
и последовательная отправка уведомлений, сохраняющая цель клика каждого
показанного результата. Новый tray_contract проверяет два результата,
промежуточное уведомление без результата и восстановление после Explorer.
Итоговый повторный прогон: 29/29 PASS, 155.32 s.
Лог: build/release-0.7.0-full-ctest.log.

Проверены quiet default, сохранение старого явного выбора, три режима
уведомлений, независимые группы с ошибками/отменами и группа256 при истории100.
Контракт панели проверил разделы, скрытые несохранённые поля, сохранение
уведомлений и callback экспорта. Четыре настоящих раздела отдельно осмотрены
в нативном стенде ControlPanel без трея, hooks и mutex основного приложения.

Реальные файловые проверки: эксклюзивная блокировка исходного PNG; сообщение
с действием «закройте»; последующая JPEG-конвертация с Unicode/длинным именем;
неизменный SHA256 оригинала; запрет записи настоящим ACL только в отдельной
фикстуре с восстановлением исходного ACL; отсутствие частичного результата.
Заполненный физический диск не создавался — проверены коды Win32 и сообщения.
Журнал проверен на предел256 КиБ, строгий экспорт кодов событий, фильтрацию
подставленного текста и отказ перезаписывать существующий отчёт.

Существующие реальные конвертации Office, PDF, видео, аудио, AVIF, WebP, TIFF,
HEIC, PPTX, OCR rus/eng/aze, NVIDIA/Intel и CPU fallback входят в общий прогон.

Работающая пользовательская копия на Desktop не завершалась и не заменялась;
application_smoke и установка в реальный профиль повторно не запускались.
Настоящий жест Explorer/Desktop с удержанием Shift, физические смешанные DPI,
отдельная Windows10 и чистая Windows11 остаются ручной приёмкой. Синтетические
OLE, геометрия и lifecycle не считаются доказательством этих сценариев.
Подробная матрица: docs/acceptance-0.7.0.md. Текущее приложение пользователя
не считается обновлённым или запущенным из этого выпуска.
