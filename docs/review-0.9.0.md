# Независимый обзор 0.9

Один read-only обзор всей ветки 6a7e69b..a8f2185, gpt-6-astra, high. Обозреватель не менял файлы, не запускал приложение, не использовал авторизацию и не выполнял установки. Повторный обзор после исправлений не проводился: исправления проверены воспроизводящими тестами и регрессией.

Два существенных замечания исправлены одним проходом:

1. Полная сборка копировала лишние/изменённые файлы из tools/modules с доверенной квитанцией. `package_policy` воспроизвёл оба случая RED. Теперь staged payload строится только по закреплённому инвентарю, проверяет размер/хеш каждого скопированного файла, запрещает ссылки, неизвестные файлы/модули; производственная подготовка установщика повторно проверяет готовое дерево. Тесты GREEN, включая изменение того же размера и дополнительный личный файл после упаковки. При сборке реального комплекта найдена и исправлена чувствительность ASCII-проверки к Unicode case folding; отдельный LICENSE-сценарий RED→GREEN.
2. Имя core/full установщика могло расходиться с составом; неизвестная метка принималась как full. Тесты обоих направлений, отсутствующей и неизвестной метки RED. Теперь метка обязательна, допустимы только точные core/full, запрос обязан совпадать, путь по умолчанию определяется из типа. Все отрицательные сценарии и правильный core GREEN.

Полный CTest после прохода: 36/36, 159,40 с. Последние дополнительные native callback/ASCII проверки запускаются отдельно; итоговый статус — в отчёте выпуска. Замеры производительности проводились отдельно от сборки/регрессии.

Небольшое отложенное замечание: после успешного переключения модуля ошибка удаления временного CAB может показать ошибку установки, хотя новая версия уже активна. Например, сторонний процесс может разрешить чтение, но запретить удаление CAB. Повторная проверка списка покажет установленную версию; исходные файлы и работа конвертера не повреждаются. Исправление статуса/очистки оставлено следующей версии.

Решения по исключённым из обзора проверкам:

- Настоящие ключи подписи ещё не предоставлены. Выпускается unsigned preview с закреплёнными хешами; проверка архивов и публикация выполняются отдельно после исправлений. Цена ошибки решения — пользователь мог бы принять preview за подписанный stable, поэтому тип выпуска указан явно.
- Подписанный stable workflow не запускался и не активирован. Stable остаётся 0.7.0. Цена ошибки — непроверенная автоматизация могла бы выпустить некорректное стабильное обновление.
- Физический drag+Shift, смешанный DPI и чистые Windows VM остаются ручной приёмкой. Цена ошибки — платформенные/жестовые дефекты могут не выявляться синтетическими тестами.
- Короткие локальные измерения не распространяются на большие реальные файлы. Параллельная очередь не добавлена. Цена ошибки — затраты памяти/CPU и время пользовательской нагрузки могут отличаться.
