# Проверка профилей конвертации 0.16

Статус: реализация и исправления ревью завершены; финальный Full runner — **59/59 PASS, 304.07 с**, без автоматических пропусков, `fixtures_removed=true`. Работа только локальная, ручные тесты пропущены по указанию владельца. Установщики/ZIP не создавались, GitHub/каналы/сертификаты не менялись.

## Что реализовано

- Профили по семи категориям, явное сохранение, шаблоны и активный выбор. Формат профиля только меняет порядок уже разрешённых секторов; параметры действуют на совпадающий сектор.
- Снимок параметров и подписи профиля в задаче, включая группу и повтор. Отсутствие модуля не уничтожает определение профиля и не запускает загрузку.
- Последствия формата в нативном редакторе, отдельные общие настройки и исправимые ошибки черновика. Для видео → MP3/WAV показаны только параметры извлечения аудио.
- Подтверждённые движки и кодировщик/backend/fallback, время Worker и байты. WIC измеряется на своей временной копии до публикации; папки страниц/листов — без рекурсивного обхода или перехода по ссылкам. Отмена/ошибка сбрасывает размер результата.
- Старый INI читается без сброса, SWQ4 читает SWQ1/2/3. Чистое восстановление не пишет состояние только ради миграции; реальные прерванные задачи сохраняют прежнюю политику Interrupted/паузы.

Пользовательская инструкция: [conversion-profiles.md](conversion-profiles.md). Дизайн и четыре задачи: [спецификация](superpowers/specs/2026-10-24-conversion-profiles-design.md), [план](superpowers/plans/2026-10-24-conversion-profiles.md).

## Принятые решения

- Реализация выполнялась в текущей локальной ветке после прямого согласования дизайна; повторное согласование технического плана не запрашивалось. Это решение о ходе работы, без изменения согласованного сценария.
- Имена профилей хранятся валидным UTF-8 после первого `=` в INI; управляющие символы запрещены вместо экранирования многострочных значений. Цена ограничения: многострочное имя сохранить нельзя, как и предусмотрено дизайном.
- Новый идентификатор staging короче: 16 hex вместо строкового GUID с разделителями. Папка всё равно создаётся атомарно, существующая никогда не используется. Цена крайне редкой коллизии — отказ текущего запуска, не перезапись чужих данных; все слишком длинные пути Office это не устраняет.
- Замечание ревью о видео-параметрах для MP3/WAV принято как существенное по поведению: показаны и применяются параметры аудио, а высота/кодек/GPU скрыты. Цена изменения — активный профиль извлечения аудио теперь явно определяет его битрейт вместо неработающих видео-полей.

Отложенных замечаний ревью нет. Ограничения read-only ревью физических DPI/Проводника приняты как ограничения проверки по указанию владельца; GPU дополнительно проверяется настоящими автоматическими конвертациями.
