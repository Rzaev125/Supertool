# Профили конвертации

Локальная версия 0.16 позволяет сохранить формат и параметры под своим именем. Откройте **Настройки → Конвертация**, выберите категорию и нажмите «Создать» либо один из шаблонов фото, видео или аудио. Задайте параметры, выберите профиль в поле «Активный профиль» и нажмите **«Сохранить настройки»**.

Стартовые шаблоны:

| Шаблон | Параметры |
| --- | --- |
| Фото для отправки | JPG, сторона до 1920 px, Balanced, без метаданных |
| Видео 1080p | MP4/H.264, высота до 1080 px, Balanced, Auto GPU → CPU |
| Аудио для телефона | MP3, 192 кбит/с, Balanced |

Шаблоны можно менять. Маленькие исходники не увеличиваются. Фактический вес файла зависит от содержимого и кодировщика; он заранее не рассчитывается.

В каждой категории активен один профиль или «Общие настройки». Формат активного профиля перемещается в начало уже разрешённых секторов колеса. **Параметры профиля действуют только при выборе его формата.** Например, «Фото для отправки → JPG» уменьшает выбранный JPG, а сектор PNG использует общие настройки ниже редактора профилей. Сектор нужно выбрать явно; центральная зона по-прежнему отменяет жест.

Скрытые форматы и форматы без установленных модулей не появляются в колесе. Профиль остаётся в настройках, где указана причина недоступности. Установка модулей автоматически не начинается. Сохранить недоступный профиль можно для последующего использования.

Редактор показывает последствия выбора: ограничение размеров, прозрачность/белый фон, режим метаданных, условное преобразование поддерживаемых HDR AVIF/HEIC в SDR, потери при перекодировании и ограничения OCR. Подсказки описывают маршрут, а не анализируют перетаскиваемый файл. Анимация сохраняется в поддерживаемых GIF/WebP; при выводе в статические форматы остаётся первый кадр.

Для профиля категории «Видео» с выходом MP3/WAV редактор показывает извлечение аудио и его параметры. Высота, видеокодек и GPU-кодирование к этому маршруту не применяются. MP3 использует заданный битрейт, WAV не имеет выбора битрейта и качества сжатия.

Переключение профилей и разделов сохраняет черновик. Некорректные значения блокируют применение и переход к другому профилю, пока они не исправлены. «Удалить» удаляет выбранный профиль из черновика; сохранение применяет удаление. «По умолчанию» восстанавливает общие параметры и отключает активные профили, сохраняя определения ваших профилей.

Уже добавленная задача хранит собственные параметры и название профиля. Последующее редактирование или удаление профиля не меняет очередь. «Повторить» использует прежние параметры; время и сведения выполнения измеряются заново. Для группы действуют те же правила, общая папка результатов и одно сводное уведомление. Панель задач автоматически не открывается.

В подробностях задачи доступны профиль, исходный размер, размер опубликованного результата, время Worker без ожидания в очереди и подтверждённые этапы движков. Для видео/аудио указывается успешный кодировщик; для видео — его CPU/NVIDIA/Intel/AMD backend и переход на CPU после неудачного GPU-кодирования, если он был. Обнаружение GPU само по себе не считается аппаратной конвертацией. Ошибка/отмена не имеет размера успешного результата; старые записи без измерений показывают «нет данных».

Профили хранятся в существующем INI одним атомарным сохранением: до 32 профилей, название до 64 UTF-16 единиц, без управляющих символов, уникальное внутри категории без учёта регистра. Старый INI читается без сброса настроек; новый INI с профилями может не читаться старым EXE. Новое состояние очереди SWQ4 читает SWQ1/2/3; чистая история не переписывается только ради смены версии.

Ручные проверки Проводника и физических DPI пропущены по указанию владельца. Профили проверяются нативными контрактами панели, автоматическими преобразованиями и штатным Full runner; это не заменяет ручную приёмку настоящего жеста.
