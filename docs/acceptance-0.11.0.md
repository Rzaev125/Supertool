# Приёмка 0.11 preview

Исправлены оставшиеся противоречия README о GIF/анимированном WebP. Новый контейнерный fixture вручную задаёт ANMF blend/offset, перекрытие альфа 128/64, неравные задержки и конечный loop. Независимый alpha-over оракул допускает до двух уровней округления после двух наложений; каждый пиксель результата round-trip сравнивается с декодированным оригиналом точно. No-blend mutant обнаруживается.

HEVC/AV1: [выбор кодека и ограничения](video-codecs.md). Проверены INI/worker options, SWQ2 с чтением SWQ1, UI сохранение/восстановление, несовместимые контейнеры до запуска движка, отмена без повторов, безопасный cleanup и CPU fallback того же кодека. CPU-кодеки и все контейнеры/пресеты дают полностью декодируемые результаты с ожидаемыми размерами, кадрами, звуком, тегами и PSNR >25 dB на синтетическом SDR-наборе. Это не оценка качества на всех пользовательских видео.

Реальное оборудование: HEVC NVENC и Intel QSV; AV1 CPU после отказа GPU-проб. Успешный AV1 GPU и AMD AMF не проверены. Декодирование, фильтры и звук CPU; новых фоновых процессов и пакетов движков нет.

Общая регрессия: 38/38, 186,24 с; /W4 без предупреждений. Один независимый обзор без блокирующих замечаний: [точный охват PSNR, решения и ограничения](review-0.11.0.md). Упаковка и публикация фиксируются отдельно после проверки артефактов. Исторические приёмки не переписываются. Stable 0.7.0, модульные pins 0.9.0 не меняются. Физический Explorer drag+Shift, разные DPI, чистая VM и настоящая подпись остаются непроверенными. HDR/метаданные — следующий самостоятельный этап.
