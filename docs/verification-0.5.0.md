EXE: **674816 байт**, статическая CRT, ProductVersion **0.5.0**,

## Автоматические проверки

Все **26 проверок CTest имеют успешный результат**. Полный прогон занял
268.76 секунды: 25 прошли, тест упаковки выявил конфликт загрузки модулей
PowerShell 7 и Windows PowerShell 5.1 через CTest. Скрипты теперь загружают
Utility/Archive из каталога фактического хоста. Повтор упавшего теста
в том же окружении: **1/1, 1.15 секунды**. Код приложения после полного
прогона не менялся. Журналы:

- `build/release-0.5.0-full-ctest.log` — исходный полный прогон;
- `build/release-0.5.0-installer-payload-ctest.log` — успешная перепроверка.

Пройдены настройки и снимки заданий, интерфейс панели, очередь, история,
прогресс, отмена и worker-протокол, OLE CF_HDROP, анимации, запуск и завершение,
а также настоящие конвертации PDF, Office, видео, аудио, AVIF, WebP, TIFF,
HEIC, презентаций и OCR. OCR проверен на русском, английском и азербайджанском.

## Аппаратное видео

- NVIDIA GeForce GTX 1660 SUPER, драйвер 32.0.16.1714: реальное кодирование
  NVENC для всех трёх пресетов. Автоматический режим выбрал NVIDIA.
- Intel UHD Graphics 770, драйвер 32.0.101.7088: реальные QSV-конвертации
  всех пресетов при исключении NVIDIA только в тестовом стенде.
- AMD отсутствует: настоящий отказ инициализации AMF из-за отсутствующей
  `amfrt64.dll` привёл к CPU. Успешное кодирование на AMD не подтверждено.
- MP4/MKV/MOV, H.264 + AAC, сохранение звука, масштабирование нечётных
  размеров 641×361 до 426×240 и полное строгое декодирование результатов.
- NVIDIA на этой машине отклонила настоящий кадр 128×128 после успешной
  пробы 256×256. Приложение повторило задачу на CPU и создало корректное видео.
- Проверены отсутствие GPU, отказ после создания частичного результата,
  единственный CPU-повтор, отдельные логи, отмена без повторного кодирования,
  сохранность источника и чужого результата, исключительная публикация.
- Этап прогресса называет кодировщик; после GPU-ошибки виден переход на CPU.
  Только публикация готового результата выдаёт 100%.
- Новый параметр Auto/CPU сохраняется в INI и снимке задания; старый INI
  без ключа получает Auto. CPU-only не запускает пробу GPU.

Подробности и команды: [аппаратное видео](hardware-video.md).
GPU ускоряет H.264-кодирование. Декодирование, фильтры, звук и WebM остаются
на CPU; пресеты разных кодировщиков не обещают одинаковое качество/размер.

## Установщик

Проверена полная тестовая сборка с тем же приложением и модулями:
**19512 файлов**, хеш каждого установленного файла сверён с манифестом.
Установка, повторная установка/обновление и удаление прошли в выделенной
папке `build/installer-tests/full-050-verified`.

- Установленная копия запустилась, создала собственное окно контроллера
  и штатно завершилась. Обновление во время её работы было заблокировано.
- Через установленный EXE и его модули выполнены настоящие конвертации видео:
  числовой прогресс, завершение после публикации, прежний CLI, ошибки/коллизии
  без ложного 100%, сохранность оригиналов.
- Проверены отказ при занятом mutex, чужом пути установки и отсутствии
  обязательного переключателя для тестовой сборки. Процессы не уничтожаются.
- Все файлы payload удалены; INI и добавленные файлы в корне и вложенной папке
  сохранены. Малый пакет отдельно проверил замену EXE при переходе 0.4 → 0.5.
- Тестовая сборка отключает регистрацию/ярлыки. Реальный профиль пользователя
  не изменён. Обычная интеграция в меню «Пуск» и список приложений проверена
  по скрипту, без установки в настоящий `%LOCALAPPDATA%\Programs`.
- Проверены фильтрация личных/временных файлов, соответствие версии и хеша
  EXE, отказ для путей через junction/reparse point, происхождение компилятора.

Журналы установки, обновления, удаления, запуска и конвертации, а также
`results.json` находятся в `build/installer-tests/full-050-verified`.
Полная тестовая сборка использовала окончательные EXE/модули; финальный
дистрибутив обновляет только документацию с результатами этих проверок.

Inno Setup завершает удаление своего EXE отдельным дочерним процессом после
выхода исходного процесса. Первый тест завершался раньше этой фазы, и sandbox
останавливал очистку. Исправленный стенд ожидает исчезновения `unins000.exe`
и завершения журнала. Два повторных прогона малого пакета в sandbox прошли;
остались только три ожидаемых пользовательских файла. Отдельный результат:
`build/installer-tests/febac767f81946169736c33e35391ae5/results.json`,
`uninstall_self_cleanup=true`. Код самого установщика менять не потребовалось.

Установщик устанавливает полный комплект для текущего пользователя без
загрузок, служб, драйверов и обязательного автозапуска. Он **не подписан**
цифровой подписью издателя. SHA-256 поставляется отдельно и не заменяет подпись.
Подробности: [установка и удаление](installer.md).

## Ресурсы и совместимость

В коротком smoke-замере трей использовал **16.3 MiB**, **62.5 мс CPU за
2005 мс**. Это наблюдение на данной машине, не гарантия для всех систем.
Пробы GPU выполняются только во время конвертации. В простое не появляются
новые фоновые процессы или таймеры; движки запускаются на время задания.
Ограничение CPU-потоков не ограничивает загрузку GPU.

Исходные пользовательские INI в build/Release и out/Supertool сохранены
побайтно. Их SHA-256:
`8CE707D2AA49B20D97C28554A09A4138C216107ED5E160D5CB8841E5E1D11E68`.
Личные настройки исключаются из ZIP и установщика. Предыдущие ZIP-выпуски
и отчёт `docs/verification-0.4.0.md` сохранены. Независимое ревью проверило
настройки, UI, GPU, владение результатом, отмену, установщик и упаковку.

## Не подтверждено вручную

Полный жест drag → Shift → drop из настоящего Проводника, переход между
физическими мониторами разного DPI и чистая Windows без средств разработки
отдельно не проверены. OLE/DPI-тесты не заменяют эти проверки.
Успешное кодирование на AMD и обычная регистрация установки в рабочем
профиле пользователя также не проверены. Ограничения HEIC/HDR, OCR,
презентаций и форматов перечислены в README и документации модулей.
