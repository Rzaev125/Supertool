# Приёмка локальной 0.12.0

Рабочий каталог: D:/IT/Project/Supertool. Новая версия пока не опубликована; стабильный канал и preview 0.11 не меняются.

Профильные проверки: Task 1 — 6/6, 15.87 с; Task 2 — 4/4, 7.81 с. После чистой сборки на D полный CTest: **39/39 PASS, 254.30 с**. Сборка /W4 без предупреждений. Логи: `build/orientation12-final-build.log`, `build/orientation12-full-tests.log`.

Новый image_orientation создаёт настоящие JPEG/TIFF/WebP с каждой из восьми ориентаций и сравнивает все пиксели с независимыми преобразованиями Pillow. Проверяются несимметричный рисунок, альфа, DPI по разным осям, уменьшение, мосты в семь растровых форматов, неизменность SHA256 источника, отсутствие staging, неверные значения/типы/количества EXIF, оба порядка байт, повторные теги/блоки и конфликтующие JPEG APP1. JPEG сравнивается с допуском 3 из-за различий декодеров; TIFF/WebP без потерь — точно. Для AVIF/HEIC/GIF мостов здесь проверяется размер, полная цветовая/кадровая проверка остаётся в прежних профильных тестах.

Дата съёмки: все четыре пары JPEG/TIFF, два режима, календарная валидация, неверный тип/длина, отсутствие GPS/автора/камеры и других EXIF-тегов в результате. Панель: выбор, восстановление, отказ пустому выбору, прокрутка поля при 144 DPI. INI/worker snapshots и SWQ1/SWQ2/SWQ3 проверяются отдельно.

Реальный жест в Проводнике, несколько мониторов с разным DPI, чистая Windows VM, заполнение диска и Authenticode остаются непроверенными здесь. Автоматические HWND/OLE и CLI-тесты не заменяют эти проверки. Новых утверждений о скорости или RAM нет.

Удаление старой C-копии повторено по разрешению владельца: Windows блокирует атомарное переименование папки, скрипт завершился с кодом 3 без удаления. Основной проект на D сохранён.
