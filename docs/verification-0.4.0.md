## Новые возможности и проверки

- HEIC/HEIF: настоящие HEVC encode/decode, Unicode, прозрачность, все растровые
  переходы, размеры и пресеты, ICC → sRGB, поворот/отражение/кадрирование.
  Проверены отказы для повреждений, превышения размеров, HDR/PQ/CLLI,
  последовательностей, нескольких кадров и отсутствующего модуля.
- Презентации PPTX/PPT/ODP: PDF и PNG/JPG всех слайдов, включая скрытые;
  порядок, текст, пропорции и пиксели, экспорт PPTX, ODP roundtrip, legacy PPT.
  Проверены подменённый DOCX, повреждения, макросы, отсутствующий модуль,
  коллизии и сохранность источников.
- PDF OCR → TXT: реальные сканы на английском, русском и азербайджанском,
  включая ə/ı/ş/ç/ö/ü/ğ. Проверены порядок смешанных текстовых/сканированных
  страниц, пустые страницы, отключённый OCR, отсутствие движка/моделей,
  Unicode в именах источника/результата и папке самого приложения.
  Обычный текстовый PDF обрабатывается без модуля OCR.
- Engine: Unicode-safe stdin/stdout handles, отдельный stderr, отказ при
  коллизии результата, ограниченное наследование дескрипторов, таймаут и
  завершение дочерних процессов. Tesseract получает PNG через stdin и
  возвращает UTF-8 через stdout: это исправляет его narrow-path ограничение.
- Настройки: язык OCR, включение распознавания, категория презентаций,
  миграция прежнего стандартного колеса изображений с добавлением HEIC.
  Пользовательские подмножества/порядок и явно скрытый HEIC сохраняются.
- Сохранены и пройдены проверки старых форматов, пресетов, очереди, истории,
  отмены, протокола worker, OLE CF_HDROP, анимаций и панели настроек.
- Окно настроек визуально осмотрено через computer-use: все три языка
  включены, подписи читаемы. Превью HEIC и PPTX осмотрены; все восемь PNG
  пересозданы реальным Direct2D-кодом.
- Независимое ревью обнаружило, что placeholder-only текст мог подавлять
  OCR. U+FFFD/U+FFFE/U+FFFF исключены из meaningful_text. Интеграционная
  фикстура проверяет fallback, но текущий PDFium уже удаляет её U+FFFD:
  она не демонстрирует RED именно для дополнительного защитного условия.
  Других конкретных замечаний в проверенных новых путях не найдено.

## Сборка и ресурсы

- EXE: **657408 байт**, статическая CRT, manifest 0.4.0.0, Common Controls v6.
- SHA-256: `FB43D83EABF2B81674D52BA739EA858225823C64B5AB363104C2806255FAF2AF`.
- В smoke-тесте трей использовал **16.3 MiB**, **31.3 мс CPU за 2013 мс**.
  Это короткий замер на данной машине, а не гарантия для всех систем.
- Обработка последовательная, движки запускаются на время задачи с
  пониженным приоритетом. Потоки FFmpeg/AVIF/HEIC задаются настройкой
  нагрузки; выбранный OCR build без OpenMP распознаёт одним потоком.
- Портативный комплект включает libheif 1.23.6/x265 и Tesseract
  5.5.3.20260724 с eng/rus/aze/aze_cyrl. Загрузчики используют закреплённые
  SHA-256; бинарные зависимости и лицензии перечислены в документации.
  Системные установки, службы и Python runtime приложению не нужны.
- Персональный ShiftWheel.ini исключается из ZIP без удаления с диска.
  Предыдущие выпуски и исходные пользовательские настройки сохранены.

## Ограничения и ручная приёмка

Полный жест drag → Shift → drop из настоящего Проводника и переход между
физическими мониторами разного DPI вручную не подтверждены. Доступный API
автоматизации не удерживает Shift во время drag; OLE/DPI-тесты этого не
заменяют. Чистая Windows без инструментов разработки отдельно не проверена.

HEIC ограничен статическими 8-битными SDR-изображениями; HDR, серии и карты
глубины отклоняются. OCR выдаёт TXT, без поискового PDF, и может ошибаться.
Если одна страница содержит настоящий текст и скан, используется текстовый
слой; отдельные области скана пока не распознаются. Презентации в PDF/PNG/JPG
статические; заметки, анимация и воспроизведение медиа не экспортируются.

Очередь и история живут только в текущем сеансе. Сетевые пути,
placeholders/reparse points, анимация изображений, многостраничный TIFF,
HDR, GPU-кодеки, установщик и обновления в релиз не входят.
Подробности: README.md, docs/heic-module.md, docs/presentation-module.md,
docs/ocr-module.md. Предыдущий отчёт: verification-0.3.0.md.
