# Проверка обновлённого выпуска Supertool 1.0.0

24 октября 2026, Windows 11 x64. Владелец прямо распорядился удалить первоначальный выпуск и опубликовать новую сборку с тем же номером 1.0.0. Предложение повысить номер до 1.0.1 отменено до изменения версий. Уже установленная прежняя 1.0.0 требует ручной установки: автоматическая проверка не считает равный номер более новым.

## Сборка и проверки

- Отдельный Release-кандидат: `SHIFTWHEEL_LOCAL_DEVELOPMENT=OFF`, существующий публичный ключ `shiftwheel-prod-1`, версия 1.0.0. EXE, ProductName/InternalName и OriginalFilename используют Supertool. Рабочая локальная сборка и пользовательский INI не заменены.
- **Full 61/61 PASS, 460,83 с**, без автоматических пропусков; runner удалил фикстуры. Пройдены нативные контракты, запуск приложения, worker, изображения/метаданные/HDR, видео/аудио/GPU fallback, документы, презентации, OCR и HEIC. Это время полного набора при одновременной упаковке, не показатель производительности конвертации.
- SHA-256 EXE в Core и Full: `acadd373fdc13a8ec5528b23a0ace18d35a28efbe96c847e99212962dc5310e6`.
- Core ZIP содержит 45 файлов, Full — 19545, включая 19500 файлов модулей. Проверены SHA-256 каждого файла, описи/квитанции модулей, точное совпадение ZIP и полезной нагрузки установщика. Личного INI, очереди, диагностик, частичных результатов или приватных ключей нет. В обоих ZIP есть ровно один `Supertool.exe` и нет `ShiftWheel.exe`.
- Core ZIP: 778865 байт; Full ZIP: 630664430 байт. Оба установщика имеют ProductName Supertool и ProductVersion 1.0.0.
- Изолированные Core/Full установщики прошли установку, проверку всех 45/19545 файлов, повторную установку и удаление. Проверены запреты при работающем приложении, неправильном каталоге и отсутствии тестового флага; INI и посторонние файлы сохранены. Настоящие ярлыки и регистрация пользователя не менялись. Установленный Full выполнил медиаконвертацию с прогрессом и сохранением исходников. Обновление реально зарегистрированной старой установки отдельно не проверялось.
- Все шесть модулей сохраняют версию 0.9.0, исходные байты, размеры и хеши. Новый каталог использует `Supertool-module-*`; прежние имена CAB публикуются как byte-identical aliases для установленных старых Core-каталогов. Это не старые пакеты приложения.
- Свежий обзор изменений не выявил замечаний P1/P2/P3. Старые неработающие копии `ShiftWheel.exe` в двух папках Release удалены по замечанию владельца; совместимая локальная копия больше не создаётся.

## Подпись и публикация

Новый манифест указывает на `Supertool-1.0.0-win-x64-setup.exe`, подписан существующим ключом и проверен нативным verifier с минимальной версией 1.0.0. Ключ не копировался в проект и не выводился. Публичный pin и формат подписи не менялись.

EXE и оба установщика имеют фактический Authenticode-статус **NotSigned**: сертификат Windows Code Signing пока не подключён. Требования сертификата в CI не ослаблены.

До удаления старого релиза/тега сохранены их публичные метаданные. Исходники фиксируются в новой ревизии, тег v1.0.0 переносится на неё по прямому распоряжению владельца; main обновляется без принудительной перезаписи. Публикация включает пять основных пакетов, каталог, двенадцать CAB, контрольные суммы и два манифеста: всего 38 файлов. Каналы переключаются только после проверки удалённых хешей/размеров и публичной доступности.

Страница назначения: [Supertool 1.0.0](https://github.com/Rzaev125/Supertool/releases/tag/v1.0.0). Итоговая публичная проверка фиксируется после публикации.
