## Исправление подготовки CI

Обнаружены два устаревших значения по умолчанию: release workflow0.11.0 и
make-update-manifest.ps1 0.8.0 при текущей версии0.14.0. Новый
`python tests/release_config_tests.py` сначала воспроизвёл оба несовпадения
(`build/readiness14-red.log`), после согласования прошёл (`build/readiness14-green.log`).

Guard сравнивает CMake с текущими строковыми/числовыми ресурсами EXE, встроенной версией,
установщиком, скриптами пакетирования/манифеста, заголовками README/START и default version input
workflow. Исторические документы и независимые версии модулей/actions не сравниваются.
Дубликат или отсутствие ожидаемого объявления также приводит к отказу.
Четыре испорченные фикстуры это подтвердили: `build/readiness14-mutations.log`.

Workflow запускает guard после setup-python, до bootstrap/проверки ключей/сборки/подписи.
Существующие требования настоящего pin/key ID, сертификата и запрет публикации вне main сохранены.
Скрипт генерации манифеста не запускался, файлы updates/stable.txt и stable-signed.txt не менялись.
Синтаксис PowerShell проверен Parser API. Полный YAML parser/actionlint локально отсутствует:
запуск на GitHub и проверка workflow в runner здесь не заявляются выполненными.

Свежий профильный CTest: **4/4 PASS4.05с** (`update_signature`, `signing_interop`,
`update_state`, `updates_policy`), `build/readiness14-focused.log`. Ключ interoperability теста
одноразовый, удалён самим существующим тестом; это не настоящий ключ обновлений.
Полный runtime набор43/43 PASS270.70с относится к предыдущему этапу и не повторялся:
производственный код не менялся, пользователь может параллельно проверять тестовую tray-копию.

## Ручная приёмка

Пользователю предложен конкретный сценарий в собственной тестовой копии:
`build/ui-acceptance-0.14/ShiftWheel.exe`, файл `fixtures/SHIFT-TEST.png`, drag+Shift → JPG.
Результат ожидается; отсутствие ответа не считается успешной проверкой.
Доступный computer-use API не поддерживает удержание Shift между действиями,
поэтому автоматические OLE-проверки не выдаются за реальный жест.

Открыто: подтверждение физического жеста/отмены, mixed DPI, заполненный диск, чистая VM,
настоящий переход между версиями/вход после перезагрузки, реальные ключи/сертификат и первый
подписанный запуск CI. Готовые локальные0.14 пакеты и их прежние хеши сохранены:
[артефакты](artifacts-0.14.0.md).
